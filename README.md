# 코딩빌리지 🏡

**사람과 사람이 이어지는 마을** — 진로탐구아카데미 전시용 링크트리입니다.

버튼을 세로로 쌓는 대신, 굽은 길을 따라 건물이 하나씩 서 있는 **마을 지도**로 보여 줍니다.
아이들은 QR로 들어와 길을 따라 올라가며 앱을 하나씩 체험합니다.

## 빠른 시작

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 `http://localhost:3100`을 엽니다.

## 내 것으로 바꾸기

고칠 파일은 **`src/content/village.json` 하나**입니다. 코드는 건드리지 않아도 됩니다.

| 항목 | 위치 | 설명 |
|---|---|---|
| 마을 이름·검색 문구 | `meta` | 탭 제목, 공유 문구, 검색엔진 확인 코드 |
| 첫 화면 문구 | `hero` | `title`의 `\n`은 줄바꿈입니다 |
| 둘러보는 법 | `guide` | `icon`은 `tap` · `walk` · `flower` 중 하나 |
| **건물(=링크)** | `places` | 이 배열의 순서가 곧 길의 순서입니다 |
| 맺음말 | `footer` | 마지막 인사말 |

### 건물 하나 추가하기

`places` 배열에 넣기만 하면 **길이 저절로 늘어나고** 좌우 자리도 알아서 잡힙니다.
좌표를 손으로 적을 일은 없습니다.

```json
{
  "id": "praise-shower",
  "name": "칭찬 우체통",
  "kind": "postoffice",
  "theme": "관계",
  "blurb": "친구에게 칭찬 한 줄을 남겨요.",
  "howto": "이름을 고르고 칭찬을 적으면 그 친구에게 전달됩니다.",
  "href": "https://…",
  "accent": "bloom",
  "status": "open"
}
```

- `kind`는 건물 그림입니다: `gate` · `bookhouse` · `greenhouse` · `postoffice` · `plot`.
  새 그림이 필요하면 `src/components/VillageMap.tsx`의 `BuildingArt`에 `viewBox="0 0 100 100"` 기준으로 더합니다.
- **`href`를 비워 두면 자동으로 「준비 중」**이 됩니다. 상태를 손으로 적을 필요가 없습니다.
  전시 전에 자리만 잡아 두고 싶을 때 쓰세요.
- `status: "landmark"`는 누를 수 없는 장식용입니다(마을 입구처럼).
- `/`로 시작하는 주소는 같은 창에서, `http`로 시작하는 주소는 새 창에서 열립니다.

## 계절

마을은 **주마다 봄 → 여름 → 가을 → 겨울**로 바뀝니다.
이건 「10점짜리 행복 정원」과 **똑같은 계산식**(`src/lib/village.ts`의 `seasonOfWeek`)을 씁니다.
같은 주에 두 앱의 계절이 어긋나면 아이들이 헷갈리기 때문입니다.

화면 위쪽 계절 단추로 직접 바꿔 볼 수도 있습니다(전시 당일에 원하는 계절로 고정하고 싶을 때).

## 색을 바꾸고 싶다면

`src/app/globals.css` 맨 위 `:root`와 `.cv-root[data-season="…"]` 블록의 변수만 고치면 마을 전체 색이 바뀝니다.
개별 규칙에 색을 직접 적지 않습니다. 클래스 접두어는 `cv-`로 통일합니다.

GitHub에 올린 뒤 Vercel에서 저장소를 연결하면 `main`에 push할 때마다 자동 배포됩니다.
커스텀 도메인을 붙였다면 Vercel 환경변수에 `NEXT_PUBLIC_SITE_URL`을 넣어 주세요.

# 꽃 우체국 (방명록)

전시에 온 **손님이 학생 한 명을 골라 꽃 한 송이와 한 마디를 놓고 가는** 방명록입니다.
「10점짜리 행복 정원」과 방향이 반대입니다 — 학생이 자기 행복을 심는 게 아니라, 손님이 남의 정원에 놓습니다.

| 주소 | 누가 | 무엇을 |
|---|---|---|
| `/guestbook` | 전시 손님 (폰) | 학생 고르기 → 꽃 고르기 → 한 마디 → 놓기 |
| `/guestbook/board` | 전시장 태블릿 | 모두의 정원이 15초마다 저절로 차오릅니다 (스크롤 없음) |
| `/guestbook/garden` | 아무나 (폰) | 같은 정원을 보통 화면으로 + 정원 전체 카드 내려받기 |
| `/guestbook/mine` | 진탐아 학생 (전시 후) | 나에게 온 꽃다발 확인 + 카드 내려받기 |

## 설치 — 구글 시트 붙이기

1. [script.google.com](https://script.google.com) 새 프로젝트를 만들고 `gas/꽃우체국_code.gs` 전체를 붙여넣습니다.
2. `setup()` 을 한 번 실행합니다. 시트가 자동으로 만들어집니다.
3. 만들어진 시트의 **`학생명단`** 에 진탐아 학생 이름을 적습니다.
   `id`는 비워 두면 자동으로 채워집니다. `addStudents()` 함수에 이름을 넣어 한 번에 등록해도 됩니다.
4. **배포 → 새 배포 → 웹 앱**, 실행은 `나`, 접근 권한은 `모든 사용자`.
5. 나온 `/exec` 주소를 `.env.local` 의 `GUESTBOOK_GAS_URL` 에 넣습니다.
   Vercel에서는 **Settings → Environment Variables** 에 같은 이름으로 넣습니다.

`GUESTBOOK_GAS_URL` 을 비워 두면 **데모 모드**로 돌아갑니다. 예시 명단 6명이 보이고, 놓은 꽃은
서버를 다시 켜면 사라집니다. 화면을 확인하는 용도로만 쓰세요. 화면 위에 노란 띠로 표시됩니다.

## 전시 중 관리

- **부적절한 방명록**은 시트 `방명록` 의 `hidden` 칸에 `Y` 를 적으면 화면에서 즉시 사라집니다.
  지우는 것보다 가려 두는 편이 안전합니다(기록은 남습니다).
- 새 방명록을 그만 받으려면 시트 `설정` 의 `open` 을 `N` 으로 바꿉니다.
- 받은 꽃 **개수는 어느 화면에도 나오지 않습니다.** 못 받은 사람이 드러나지 않게 일부러 뺐습니다.

## 학생 꽃다발 잠그기 (PIN)

전시가 끝나면 학생이 `/guestbook/mine` 에서 자기 꽃다발을 받아 갑니다.
그냥 두면 **이름만 고르면 남의 것도 열립니다.** 잠그려면 앱스 스크립트 편집기에서:

1. `gas/꽃우체국_code.gs` 를 편집기에 다시 붙여넣고 저장 (기존 내용 전체 교체)
2. 함수 드롭다운에서 **`setPins`** 실행 → 학생마다 4자리 PIN이 만들어지고,
   아래 **실행 로그**에 「이름 / PIN」 목록이 찍힙니다
3. **`lockBouquets`** 실행 → 이제 PIN이 있어야 열립니다
4. 로그의 목록을 학생들에게 나눠 줍니다

| 함수 | 하는 일 |
|---|---|
| `setPins()` | 비어 있는 PIN 칸만 채웁니다. 이미 있는 건 안 건드립니다 |
| `showPins()` | 만들어진 PIN 목록을 다시 찍어 줍니다 |
| `lockBouquets()` | PIN을 실제로 요구하게 켭니다 |
| `unlockBouquets()` | 다시 PIN 없이 열리게 합니다 |

**웹 앱을 다시 배포할 필요는 없습니다.** 이 함수들은 시트만 건드립니다.

특정 학생의 PIN을 새로 뽑고 싶으면 그 줄의 `pin` 칸을 지우고 `setPins()` 를 다시 실행하세요.
PIN은 1000~9999 에서만 뽑습니다 — 0으로 시작하면 시트가 앞의 0을 지워 버려(0123 → 123)
학생이 넣은 값과 어긋나기 때문입니다.

## 카드 내려받기

**「10점짜리 행복 정원」의 포토카드는 꽃만 그리고 글을 그리지 않습니다.** 받은 사람에게 정작 남는 건
글인데 말이죠. 그래서 이 카드는 **글을 먼저 세우고 꽃을 곁들입니다.**

- 학생 개인 카드 — 세로 1080px, 정원 그림 + 받은 글 전부
- 모두의 정원 카드 — 가로 1600px, 2단으로 글을 배치(양쪽 높이를 맞춰 채웁니다)

꽃은 이모지가 아니라 `src/lib/flowers.ts` 에 **좌표로 정의된 타원 묶음**입니다.
화면(SVG)과 카드(canvas)가 **같은 정의**를 읽기 때문에 둘이 어긋나지 않습니다.
꽃을 추가하려면 이 파일의 `FLOWERS` 배열에만 넣으면 양쪽에 동시에 생깁니다.
