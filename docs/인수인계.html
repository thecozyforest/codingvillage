만든 것

마을 지도 /

마을을 한 바퀴 도는 찌그러진 고리 길을 따라 건물 13곳이 서 있습니다. 건물마다 큰길로 나가는 샛길이 있고, 고리 안쪽은 연못과 우물이 있는 마을 마당입니다. 계절마다 봄 꽃잎·여름 나뭇잎과 볕·가을 낙엽·겨울 눈이 날립니다.

앱 12곳

마을 도서관(오늘의 한 마디) · 작은 행복정원 · 습관 훈련소 · 밑줄 서랍 · 말랑문법연구소 · 고전 이야기극장 · 오답 진료소 · 진로 관제탑 · 진로 나침반 · 기록 공방 · 인구 전망대 · 꽃 우체국. 건물 그림은 앱 성격에 맞춰 따로 그렸습니다.

마을 도장

들어갔다 나오면 건물에 도장이 쾅 찍힙니다. 이름과 날짜를 골라 도장판을 언제든 내려받을 수 있고, 안 들른 곳은 점선 빈칸으로 남습니다. 기기를 돌려 쓸 때는 「도장판 비우고 처음부터」로 초기화합니다.

꽃 우체국 /guestbook

이 마을에서 유일하게 「하고 가는」 곳이라, 간판에 「방명록」 딱지를 붙이고 건물을 키우고 아래에 안내 띠를 띄웠습니다. 띠는 방명록을 쓰면 저절로 사라집니다.

모두의 정원 /guestbook/board

「모두의 꽃밭」과 「정원마다 피어난 꽃」이 22초마다 번갈아 뜹니다. 정원별 보기는 이름순이고, 꽃을 못 받은 사람도 똑같이 한 칸을 차지합니다.

내 꽃다발 /guestbook/mine

학생이 자기에게 온 꽃과 편지를 카드로 내려받습니다. 행복정원 포토카드가 글을 빠뜨리던 것을 뒤집어, 이 카드에는 글이 반드시 들어갑니다.

남은 일

  1. PIN을 걸지 결정

    지금은 이름만 고르면 남의 꽃다발도 열립니다. 잠그려면 앱스 스크립트 편집기에 gas/꽃우체국_code.gs를 다시 붙여넣고 setPins() → lockBouquets()를 실행하세요. 19명분 PIN이 자동으로 만들어지고 실행 로그에 목록이 찍힙니다. 웹 앱 재배포는 필요 없습니다.

  2. 눈으로 보고 다듬기아직 아무도 안 함

    구조와 좌표와 겹침은 전부 수치로 검증했지만, 색이나 건물 그림이 보기 좋은지는 아직 아무도 판단하지 않았습니다. 폰으로 한 바퀴 돌아보고 어색한 데를 고치는 게 다음 순서로 맞습니다.

  3. 전시 당일 운영 점검

    태블릿에 /guestbook/board를 띄워 두고, docs/qr/안내판_인쇄용.html을 인쇄해 붙입니다. 기기를 여러 사람이 돌려 쓴다면 손님이 바뀔 때 「도장판 비우고 처음부터」를 눌러 주세요.

  4. 부적절한 방명록 대비

    시트 방명록 탭의 hidden 칸에 Y를 넣으면 15초 안에 화면에서 사라집니다. 태블릿 화면 자막에 방명록 글이 그대로 흘러가니, 전시 중 시트를 한 번씩 봐 주세요.

시트에서 관리하기

하고 싶은 것어디서
부적절한 방명록 가리기방명록 탭 → 그 줄의 hidden에 Y
새 방명록 그만 받기설정 탭 → open을 N
PIN 잠그기설정 탭 → requirePin을 Y
PIN 19개 자동 생성스크립트에서 setPins() 실행 → 로그에 목록
학생 추가학생명단 탭에 이름만 적고 setup() 다시 실행

■ 확인된 상태 (2026-08-28 기준)
- 마을 13곳: 입구 + 앱 11개 + 꽃 우체국. 길은 찌그러진 고리 모양
- 방명록이 GAS+구글시트에 연결됨, 데모 모드 아님
- 학생 19명 등록 / 실제 방명록 2건 저장됨 → 쓰기 경로 실서버 검증 끝
- PIN 잠금 꺼짐 (requirePin: N)
- 습관 훈련소는 학급 코드 H4H8 필요 (체험용 학급이라 공개해도 됨)
- 도장은 localStorage에 저장, 「도장판 비우고 처음부터」로 초기화 가능

   데가 있으면 그것부터 고치는 게 순서
3. 전시 당일 운영: 태블릿에 board 띄우기, QR 붙이기

■ 작업 방식
- 커밋은 항목별로 나눠줘. 마음에 안 드는 것만 골라 되돌릴 수 있게
- 배포 전에 npm run build 로 타입 확인
- 화면을 바꿨으면 실제로 띄워서 수치로 확인하고 알려줘
- 셸에서 백틱 쓰면 명령으로 먹히니 스크립트 파일로 처리할 것

먼저 CLAUDE.md 를 읽고, 위 상태가 아직 맞는지 확인한 다음 알려줘.

짚고 갈 것

이 사이트를 눈으로 평가한 사람이 아직 없습니다. 작업 내내 브라우저 화면을 띄울 수 없어서, 구조·좌표·겹침·카드 픽셀은 전부 수치로만 확인했습니다. 건물이 겹치지 않는다는 것은 알지만, 예쁜지는 모릅니다.

그러니 색이 촌스럽다거나 건물 그림이 어설프다거나 하는 건 아직 아무도 판단하지 않은 영역입니다. 폰으로 한 바퀴 돌아보고 어색한 데를 알려주시면, 그게 다음 작업의 첫 항목이 되는 게 맞습니다.
